# LocalLens MCP — Launch Copy Drafts

## Hacker News / "Show HN"

> Show HN: LocalLens MCP – sort your photos by talking to Claude, no cloud upload
>
> I built an MCP server that plugs a local, privacy-first photo organizer into Claude Desktop and Cursor. It runs face recognition, geo-sorting, and duplicate detection entirely on-device — the LLM just becomes the interface. "Find Priya's photos from Goa in 2024" turns into a natural-language multi-filter search instead of manual folder-diving; "pause that Sunday auto-sort for two weeks" edits a running schedule without reopening a settings screen. Everything's local except a one-time license check for Pro features. Would love feedback on the guardrails (source≠destination checks, path-hallucination prevention, confirm-before-delete on duplicates) since letting an LLM touch a file library is the scary part.
